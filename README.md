# Destino Cordillera - Plataforma de Turismo Local

Sitio web de promoción turística para la comuna ficticia Destino Cordillera, diseñado para dar a conocer rutas naturales, opciones de hospedaje, gastronomía típica y un canal de contacto para reservas.

## Descripción del Sitio
El proyecto busca ofrecer una plataforma visual e intuitiva para los visitantes interesados en el ecoturismo cordillerano. El sitio cuenta con cuatro vistas principales interconectadas:
* **Inicio:** Portada informativa con presentación del destino y enlaces directos a las áreas clave.
* **Panoramas:** Sección con seis actividades y excursiones destacadas, maquetadas en tarjetas con hoja de estilos externa propia sin dependencias externas.
* **Alojamiento y Gastronomía:** Opciones de cabañas, campings y restaurantes tradicionales organizados en una tabla informativa.
* **Reserva y Contacto:** Formulario para solicitar cotizaciones o cupos de actividades, junto con la ubicación y vías de contacto del centro turístico.

## Tecnologías Utilizadas
* HTML5 semántico
* CSS3 (variables personalizadas, Flexbox y CSS Grid)

## Instrucciones para Visualizar el Proyecto
1. Clonar el repositorio en su equipo local con el comando:
   `git clone https://github.com/wakxup1/Solemne-Web-Practica.git`
2. Ingresar a la carpeta principal del proyecto.
3. Abrir el archivo `index.html` directamente en cualquier navegador web (Google Chrome, Mozilla Firefox, Microsoft Edge, etc.). No requiere la instalación de servidores locales ni dependencias externas.
